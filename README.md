# oliveira.ninja landing page

Astro source for [www.oliveira.ninja](https://www.oliveira.ninja), adapted from
[Gothsec/Astro-portfolio](https://github.com/Gothsec/Astro-portfolio).

The `main` branch of this repository is reserved for the GitHub profile README.
This `gh-pages` branch contains the website source and deploys through GitHub
Pages Actions.

## Development

```bash
pnpm install
pnpm dev
pnpm build
```

## Deployment

GitHub Pages is configured to deploy from GitHub Actions. The custom domain is
configured with GitHub Pages settings/API, not with a committed `CNAME` file.

Current domain target: `www.oliveira.ninja`.
