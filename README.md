# Gabriel Oliveira

Application security and automation engineer working across secure SDLC,
DevSecOps, threat modeling, vulnerability management, and practical tooling for
delivery teams.

I like building systems that reduce manual work, make security easier to adopt,
and turn messy operational workflows into maintainable software. Current areas
of interest include application security architecture, API security, cloud and
DevOps automation, AI-assisted engineering, and self-hosted lab infrastructure.
